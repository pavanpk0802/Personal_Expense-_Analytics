# Personal Expense Analytics

## Project Overview

Personal Expense Analytics is a Python-based data analysis project that studies personal spending patterns using transaction data.

## Objectives

- Analyze total personal spending.
- Identify major spending categories.
- Study monthly spending trends.
- Compare payment methods.
- Calculate important expense KPIs.
- Create a visual expense dashboard.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
- GitHub

## Dataset

The dataset contains 300 expense transactions with:

- Expense ID
- Date
- Category
- Payment Method
- Amount

## Analysis Performed

1. Data inspection and cleaning
2. Category-wise spending analysis
3. Monthly spending analysis
4. Payment method analysis
5. Expense distribution analysis
6. KPI calculation
7. Dashboard creation

## Visualizations

- Spending by Category
- Monthly Spending Trend
- Spending by Payment Method
- Expense Amount Distribution

## Key Insights

The project identifies major spending categories, monthly spending patterns, preferred payment methods, and overall expense behavior.

## Conclusion

Personal Expense Analytics demonstrates how Python and data visualization can be used to analyze spending patterns and generate meaningful financial insights.
